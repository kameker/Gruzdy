# ESP32 + DRV8825 + M49SP-2K

После включения двигатель делает N оборотов в одну сторону, ждёт секунду,
возвращается на N оборотов и повторяет цикл. Число оборотов `REVOLUTIONS`
меняется в `src/main.cpp` (по умолчанию 5). Это число полных оборотов вала;
дробные обороты в этом примере не задаются.

Конфигурация PlatformIO рассчитана на **ESP32 Dev Module** (`esp32dev`),
как было указано в исходном проекте. Выводы можно изменить в `src/main.cpp`.

## Подключение

- GPIO25 → STEP, GPIO26 → DIR; GND ESP32 соединить с GND DRV8825.
- nENBL (ENABLE) → GND, nRESET и nSLEEP → 3,3 В, чтобы драйвер был активен.
  Названия выводов и внутренние соединения проверьте на вашей плате драйвера.
- MODE0, MODE1, MODE2 → GND: полный шаг. Не меняйте режим без пересчёта
  количества импульсов в программе.
- Каждую из двух обмоток подключить к своей паре выходов A1/A2 и B1/B2.
  Определите пары мультиметром; цвета проводов могут отличаться.
- VMOT и GND драйвера → отдельный источник питания двигателя. Установите
  электролитический конденсатор рядом с VMOT и GND по инструкции к вашей плате.
  Не подключайте и не отключайте двигатель при включённом питании драйвера.

Для стандартного M49SP-2K производитель указывает шаг 7,5° (48 шагов на
оборот). Для версии RH7-1473 02 следует проверить маркировку и параметры
обмоток: исполнение может отличаться. DRV8825 рассчитан на биполярный
двухфазный двигатель; не угадывайте подключение по цветам проводов.
Настройте ограничение тока драйвера согласно параметрам конкретного двигателя
и инструкции именно вашей платы DRV8825 до запуска. Напряжение питания VMOT
должно соответствовать как двигателю, так и драйверу; для DRV8825 рабочий
диапазон 8,2–45 В. Двигатель остаётся под током во время пауз.

Прошивка считает выданные импульсы, а не фактическое положение: при перегрузке
и пропуске шагов реальное число оборотов может отличаться. При необходимости
уменьшите скорость, увеличив `STEP_INTERVAL_US`.
