# ESP32 + DRV8825 + M49SP-2K

После включения ESP32 создаёт собственную точку доступа Wi-Fi. Двигатель
начинает движение только после команды на странице, делает заданное число
полных оборотов и останавливается. Доступны целые значения от 1 до 1000.

## Управление с телефона или компьютера

1. Загрузите прошивку на ESP32 через PlatformIO и включите питание.
2. Подключитесь к Wi-Fi **Gruzdy-ESP32**, пароль **Gruzdy2026**.
3. Откройте в браузере **http://192.168.4.1/**. Доступ в интернет для этого не нужен.
4. В окне входа введите логин **admin** и пароль **motor2026**.
5. Укажите число оборотов, выберите направление и нажмите «Вращать».
   Пока команда выполняется, следующая команда отклоняется.

Название сети и оба пароля задаются в начале `src/main.cpp`. Обязательно
замените пароли перед использованием; пароль Wi-Fi должен содержать не менее
8 символов. После изменения снова загрузите прошивку на плату. Соединение с
веб-страницей работает по HTTP, поэтому используйте устройство только в своей
доверенной сети и не используйте эти пароли для других сервисов.

Направления «по часовой» и «против часовой» зависят от подключения обмоток и
того, с какой стороны смотреть на вал. Проверьте направление при первом запуске.

Конфигурация PlatformIO рассчитана на **ESP32 Dev Module** (`esp32dev`),
как было указано в исходном проекте. Выводы можно изменить в `src/main.cpp`.

## Сборка и прошивка

Откройте папку проекта в VS Code с расширением PlatformIO, подключите ESP32 по
USB и выполните **PlatformIO: Upload**. Для сборки без загрузки на устройство
можно выполнить `pio run` в папке проекта. После прошивки подключитесь к сети
устройства, как описано выше.

## Подключение

- GPIO25 → STEP, GPIO26 → DIR; GND ESP32 соединить с GND DRV8825.
- nENBL (ENABLE) → GND, nRESET и nSLEEP → 3,3 В, чтобы драйвер был активен.
  Названия выводов и внутренние соединения проверьте на вашей плате драйвера.
- MODE0, MODE1, MODE2 → GND: полный шаг. Не меняйте режим без пересчёта
  количества импульсов в программе.
- Каждую из двух обмоток подключить к своей паре выходов A1/A2 и B1/B2.
  Определите пары мультиметром; цвета проводов могут отличаться.
- VMOT и GND драйвера → отдельный источник питания двигателя. Установите
  электролитический конденсатор рядом с VMOT и GND по инструкции к вашей плате.
  Не подключайте и не отключайте двигатель при включённом питании драйвера.

Для стандартного M49SP-2K производитель указывает шаг 7,5° (48 шагов на
оборот). Для версии RH7-1473 02 следует проверить маркировку и параметры
обмоток: исполнение может отличаться. DRV8825 рассчитан на биполярный
двухфазный двигатель; не угадывайте подключение по цветам проводов.
Настройте ограничение тока драйвера согласно параметрам конкретного двигателя
и инструкции именно вашей платы DRV8825 до запуска. Напряжение питания VMOT
должно соответствовать как двигателю, так и драйверу; для DRV8825 рабочий
диапазон 8,2–45 В. При подключении nENBL к GND двигатель остаётся под током
после остановки.

Прошивка считает выданные импульсы, а не фактическое положение: при перегрузке
и пропуске шагов реальное число оборотов может отличаться. При необходимости
уменьшите скорость, увеличив `STEP_INTERVAL_US`.
