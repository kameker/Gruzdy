## Назначение и работа

Проект содержит прошивку для ESP32 Dev Module (`esp32dev`) с Arduino и PlatformIO. Она управляет шаговым двигателем M49SP-2K через драйвер DRV8825 и веб-страницу в собственной точке доступа ESP32. Пользователь задаёт целое число оборотов от 1 до 1000 и направление; при выполнении повторный запуск отклоняется. Доступна остановка по Wi-Fi.

- Для расчёта используется 48 полных шагов на оборот. STEP подключается к GPIO25, DIR — к GPIO26; интервал шагов в коде составляет 10 000 мкс.
- Точка доступа и HTTP Basic-аутентификация настроены в `src/main.cpp`; адрес страницы по умолчанию — `http://192.168.4.1/`. Пароли по умолчанию следует заменить перед использованием. HTTP не шифрует соединение.
- Программная кнопка остановки прекращает импульсы, но зависит от связи и контроллера и не отключает питание двигателя. Для защиты нужна независимая аппаратная остановка. Программа не контролирует фактическое положение и пропуск шагов.
- Схема подключения, настройки драйвера и инструкции по использованию приведены в `README.md`.

## Основные файлы

- `src/main.cpp` — точка доступа, веб-сервер, обработчики команд и выдача импульсов.
- `src/index.html` — интерфейс и клиентская логика; файл включается в прошивку через `board_build.embed_txtfiles` в `platformio.ini`.
- `include/move_command.h` — проверка ввода и состояние движения.
- `test/test_move.cpp` — тесты проверки ввода, движения и остановки.
- `platformio.ini` — конфигурация сборки `esp32dev`.
